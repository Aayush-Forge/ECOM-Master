# Logo Setup

Drop your SRIDATTAM logo image into this folder and name it exactly:

    logo.png

Final path: `/app/public/logo.png`

- Recommended dimensions: 240 x 80 px (or any height up to ~64px)
- Background should match the site theme color `#fff3c1` (or be transparent PNG)
- The header will automatically pick up the logo on next page load.
- If the file is missing the header gracefully falls back to the SRIDATTAM wordmark.
